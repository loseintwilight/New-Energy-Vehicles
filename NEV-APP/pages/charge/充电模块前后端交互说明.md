# 充电模块前后端数据库交互说明

## 概览

充电模块涉及 **3个前端页面** ←→ **3个后端Controller** ←→ **7张数据库表** 的完整数据交互。

### 页面 / 控制器映射

| 前端页面 | 后端Controller | 基础路径 |
|---------|---------------|---------|
| `pages/charge/index` (充电站列表) | `StationController` | `/app/charge/station` |
| `pages/charge/charging` (充电中) | `OrderController` | `/app/charge/order` |
| `pages/charge/order` (订单详情) | `OrderController` | `/app/charge/order` |
| — (充电桩选择) | `PileController` | `/app/charge/pile` |

### 数据库表

| 表名 | 说明 | 核心字段 |
|-----|------|---------|
| `stad_charging_station` | 充电站 | station_id, station_name, address, longitude, latitude, total_piles, available_piles, station_status |
| `stad_charging_pile` | 充电桩 | pile_id, station_id, pile_code, pile_type, power_kw, pile_status, voltage, current_a, power_now |
| `stad_charging_rate` | 费率组 | rate_id, station_id, rate_name, pile_type(适用dc/ac), is_active |
| `stad_charging_rate_period` | 费率时段 | period_id, rate_id, period_name, start_time, end_time, energy_price, service_fee, total_price |
| `stad_charging_order` | 充电订单 | order_no, user_id, station_id, pile_id, pile_code, rate_id, rate_period_id, start_time, end_time, duration, total_energy, energy_price, service_price, total_amount, order_status, pay_status |
| `stad_charging_settlement` | 充电结算 | merchant_id, settle_date, total_orders, total_energy, total_amount |
| `stad_user_favorite` | 收藏 | user_id, target_type, target_id |

## 交互详情

### 1. 充电站列表页 → 列表查询

**页面**: `pages/charge/index` → 展示附近充电站  
**文件**: `api/charge/station.js` → `getStationList(params)`

```
前端 getStationList({lat, lng, pageNum, pageSize})
  → GET /app/charge/station/list?lat=36.67&lng=117.11&pageNum=1&pageSize=10
  → StationController.list()
  → StationServiceImpl.getStationList()
  → StationMapper.selectStationListWithDistance()
  → SQL: SELECT ... 
         FROM stad_charging_station s
         WHERE s.station_status = '1'
         ORDER BY distance ASC
         LIMIT offset, limit
  ← 返回 {rows: [站列表], total: N}
  ← AjaxResult.success(data)
  ← {code: 200, msg: "操作成功", data: {rows: [...], total: 28}}
```

**关键字段映射**:

| 数据库字段 | VO字段 | 前端显示 |
|-----------|--------|---------|
| `s.station_name` | `name` | 充电站名称 |
| `s.address` | `address` | 详细地址 |
| `s.latitude, s.longitude` | `lat, lng` | 地图位置 |
| `COUNT(p.pile_status='0')` | `freePiles` | 空闲桩数 |
| `s.total_piles` | `totalPiles` | 总桩数 |
| `s.parking_fee` | `parkFee` | 停车费说明 |
| `rp.total_price` | `price` | 单价(元/kWh) |
| Haversine公式计算 | `distance` | 距离(km) |

### 2. 充电站详情 & 充电桩列表

**页面**: 选站后进入详情/选桩  
**文件**: `api/charge/station.js` → `getStationDetail(stationId)`  
**文件**: `api/charge/station.js` → `getPileList(stationId)` (PileController)

```
前端 getStationDetail(stationId)
  → GET /app/charge/station/detail/{stationId}
  → StationController.detail()
  → StationServiceImpl.getStationDetail()
  → 并行3个查询:
     ① StationMapper.selectStationById() → stad_charging_station
     ② StationMapper.selectRatesByStationId() → stad_charging_rate JOIN stad_charging_rate_period
     ③ PileMapper.selectPileListByStationId() → stad_charging_pile
  ← AjaxResult.success(StationDetailVO)
  ← {code: 200, data: {
      stationId, name, address, lat, lng, 
      freePiles, totalPiles, 
      price: "0.90",           ← 从费率时段取当前时段价格
      electricPrice: "0.35",   ← 电价
      servicePrice: "0.55",    ← 服务费
      piles: [{                ← 充电桩列表
        pileId, pileCode, pileType, powerKw, 
        pileStatus, voltage, current, powerNow, 
        lastHeartbeat
      }, ...],
      timePrices: [{           ← 费率时段详情
        periodName, startTime, endTime, 
        electricPrice, serviceFee, totalPrice
      }, ...]
    }}
```

**充电页(`charging.vue`)在 `onLoad` 时调用此接口获取数据**:
1. 获取电站名称、地址
2. 获取充电桩实时状态（空闲/充电中）
3. 获取费率价格（更新 `this.price`）
4. 获取桩的额定功率（设置 `this.targetPower`）
5. 自动选择第一个空闲桩

### 3. 开始充电 → 创建订单

**页面**: `pages/charge/charging` → `initCharge()`  
**文件**: `api/charge/station.js` → `startCharge({stationId, pileNo, energy})`

```
前端 startCharge({stationId:1, pileNo:"AT-DC-01", energy:30})
  → POST /app/charge/order/start
     body: {stationId:1, pileNo:"AT-DC-01", energy:30}
  → OrderController.start()
  → OrderServiceImpl.startCharge()
  
  后端逻辑:
  ① 查询充电桩 PileMapper.selectPileByPileNo()
     → SELECT FROM stad_charging_pile WHERE station_id=? AND pile_code=?
     → 检查 pile_status == '0'(空闲)
  
  ② 查询费率 StationMapper.selectRatesByStationId()
     → SELECT FROM stad_charging_rate r 
       JOIN stad_charging_rate_period rp ON r.rate_id = rp.rate_id
       WHERE r.station_id = ? AND r.is_active = 1
  
  ③ 匹配当前时段:
     - 根据桩类型(pile_type: dc/ac)过滤费率组
     - 根据当前时间(LocalTime.now())匹配时段(start_time ~ end_time)
     - 支持跨天时段(如22:00~07:00)
     - 获取到 electricPrice, servicePrice, totalPrice
  
  ④ 插入订单:
     INSERT INTO stad_charging_order (
       order_no, user_id, station_id, pile_code, pile_id,
       start_time, total_energy, total_amount, 
       energy_price, service_price,  ← 存入单价
       rate_id, rate_period_id,      ← 存入费率信息
       order_status='0', pay_status='0'
     ) VALUES (...)
  
  ⑤ 更新桩状态:
     UPDATE stad_charging_pile SET pile_status='1'
     WHERE pile_id = ?
  
  ← AjaxResult.success({orderNo, electricPrice, servicePrice, totalPrice})
  ← {code: 200, data: {
      orderNo: "CO1712345678901",
      electricPrice: 0.35,
      servicePrice: 0.55, 
      totalPrice: 0.90
    }}
```

**前端接收后**:
- `this.orderNo = res.data.orderNo` — 保存订单号
- `this.price = res.data.totalPrice` — 更新单价
- `this.totalEstimate = targetEnergy * price` — 计算预估费用
- 开启轮询 `this.timer` → 每3秒调 `getChargeStatus`

### 4. 充电中实时轮询

**页面**: `pages/charge/charging` → `fetchChargeStatus()`  
**文件**: `api/charge/station.js` → `getChargeStatus(orderNo)`

```
前端 getChargeStatus("CO1712345678901")
  → GET /app/charge/order/status/CO1712345678901
  → OrderController.status()
  → OrderServiceImpl.getChargeStatus()
  
  后端逻辑:
  ① SELECT FROM stad_charging_order o
     LEFT JOIN stad_charging_station s ON o.station_id = s.station_id
     LEFT JOIN stad_charging_pile p ON o.pile_id = p.pile_id
     WHERE o.order_no = ?
  
  ② 组装返回数据:
     - status: 0=充电中, 1=已完成, 2=已取消
     - chargedTime: 已充时长(秒→分钟/小时)
     - chargedEnergy: 已充电量(度)
     - chargedAmount: 已充金额
     - chargePercent: 充电进度(若已完成=100%)
  
  ← AjaxResult.success({orderId, status, orderNo, stationName, pileNo,
      chargedTime, chargedEnergy, chargedAmount, 
      electricFee, serviceFee, totalEstimate, chargePercent})
  ← {code: 200, data: {
      orderId: "CO1712345678901",
      status: "0",
      chargedTime: "30分钟",
      chargedEnergy: "15.5",
      chargedAmount: "13.95",
      chargePercent: 50,
      ...
    }}
```

**前端每3秒轮询，更新**:
- `this.chargePercent` — 电池百分比进度条
- `this.chargedEnergy` — 已充电量
- `this.chargedTime` — 已充时长
- `this.chargedAmount` — 已充金额
- 若 `status === "1"` (已完成) → 弹出订单弹窗

### 5. 停止充电 → 费用计算

**页面**: `pages/charge/charging` → `doStop()`  
**文件**: `api/charge/station.js` → `stopCharge({orderId})`

```
前端 stopCharge({orderId: "CO1712345678901"})
  → POST /app/charge/order/stop
     body: {orderId: "CO1712345678901"}
  → OrderController.stop()
  → OrderServiceImpl.stopCharge()
  
  后端逻辑:
  ① 查询订单 OrderMapper.selectOrderByOrderNo()
     → 读取 stored energy_price(=单价), service_price(=单价)
  
  ② 计算实际费用:
     energy = order.total_energy (开始充电时传入的目标电量)
     判断单价(energy_price < 10则为单价):
       electricFee = energy * electricUnitPrice
       serviceFee = energy * serviceUnitPrice
     保留2位小数
  
  ③ 计算充电时长:
     durationSecs = (当前时间 - start_time) / 1000
  
  ④ 更新订单:
     UPDATE stad_charging_order SET
       end_time = NOW(),
       duration = #{duration},
       total_energy = #{energy},
       total_amount = #{totalAmount},
       energy_price = #{electricFee},
       service_price = #{serviceFee},
       order_status = '1',
       pay_status = '0'
     WHERE order_no = ? AND order_status = '0'
  
  ⑤ 释放充电桩:
     UPDATE stad_charging_pile SET pile_status='0'
     WHERE pile_id = ?
  
  ← AjaxResult.success({orderNo, duration, durationText, energy,
      chargedAmount, electricFee, serviceFee, total})
  ← {code: 200, data: {
      orderNo: "CO1712345678901",
      duration: 1800,
      durationText: "30分钟",
      energy: 15.5,
      chargedAmount: 13.95,
      electricFee: 5.43,
      serviceFee: 8.52,
      total: 13.95
    }}
```

**前端接收后**:
- 更新 `this.payData` 为后端返回的实际费用
- 弹出订单弹窗，显示电费、服务费、合计
- 用户可选择"确认支付"或"稍后处理"

### 注意事项

1. **前端需重启后生效**（修改了 `charging.vue` 逻辑）
2. **后端需重启后生效**（修改了 `OrderServiceImpl.java` 和 `OrderMapper.xml`）
3. **充电进度数据来源**：当前后端 `getChargeStatus` 返回的 `chargePercent` 仅在订单完成时=100%，充电中时为0%。这是因为后端没有模拟充电进度增长。测试时建议：
   - 快速验证：`startCharge` → 等待几秒 → `stopCharge` 观察费用计算
   - 或修改 `getChargeStatus` 后端逻辑，按时间比例估算进度
4. **实时功率/电流/电压**：数据库桩表有 `power_now, current_a, voltage` 字段，当前使用本地模拟值。接入真实桩数据后可从桩心跳表读取。
