# 充电页面 (`pages/charge/charging.vue`) 前后端交互说明

## 概述

充电页面通过与后端 API 接口交互实现完整的充电流程，包括：**站点信息获取 → 开始充电 → 实时状态轮询 → 停止充电 → 支付订单**，共 5 个关键交互点。

---

## 1. 获取充电站详情

| 项目 | 内容 |
|------|------|
| **触发时机** | 页面加载 `onLoad` → `initPage()` |
| **调用位置** | [`charging.vue` 第 249 行](file:///d:/NEV_Life/NEV-APP/pages/charge/charging.vue#L249) |
| **API 函数** | `getStationDetail(stationId)` |
| **请求方式** | `GET` |
| **接口地址** | `/app/charge-mini/station/detail/{stationId}` |
| **后端处理** | `StationServiceImpl` → 查询数据库 `charging_station` 表 + `charging_pile` 表 |

**请求参数：** `stationId`（充电站 ID，从上一页面路由传递）

**返回数据结构：**
```json
{
  "code": 200,
  "data": {
    "name": "XX充电站",
    "price": 1.28,
    "piles": [
      { "pileCode": "A01", "pileStatus": "0", "powerKw": 120 },
      { "pileCode": "A02", "pileStatus": "1", "powerKw": 120 }
    ]
  }
}
```

**页面使用逻辑：**
- 更新站点名称 `stationName`
- 更新电价 `price`
- 匹配充电桩编号 `pileNumber` 和额定功率 `pilePower` / `targetPower`

---

## 2. 开始充电（创建订单）

| 项目 | 内容 |
|------|------|
| **触发时机** | `initPage()` → `initCharge()` |
| **调用位置** | [`charging.vue` 第 273 行](file:///d:/NEV_Life/NEV-APP/pages/charge/charging.vue#L273) |
| **API 函数** | `startCharge(data)` |
| **请求方式** | `POST` |
| **接口地址** | `/app/charge-mini/order/start` |
| **后端处理** | 创建充电订单记录 → 插入数据库 `charging_order` 表 |

**请求参数：**
```json
{
  "stationId": 1,
  "pileNo": "A01",
  "energy": 30
}
```

**返回数据结构：**
```json
{
  "code": 200,
  "data": {
    "orderNo": "CO20250101001",
    "electricPrice": 0.35,
    "servicePrice": 0.55,
    "totalPrice": 0.90
  }
}
```

**页面使用逻辑：**
- 保存订单号 `orderNo`
- 更新单价 `price` 和预估费用 `totalEstimate`
- 启动轮询定时器 `startPolling()`

---

## 3. 轮询获取实时充电状态

| 项目 | 内容 |
|------|------|
| **触发时机** | `initCharge()` 成功 → `startPolling()` → 每 1 秒调用 |
| **调用位置** | [`charging.vue` 第 310 行](file:///d:/NEV_Life/NEV-APP/pages/charge/charging.vue#L310) |
| **API 函数** | `getChargeStatus(orderId)` |
| **请求方式** | `GET` |
| **接口地址** | `/app/charge-mini/order/status/{orderId}` |
| **后端处理** | 查询数据库 `charging_order` 表获取实时充电进度 |

**请求参数：** `orderId`（订单号，从 startCharge 返回获得）

**返回数据结构：**
```json
{
  "code": 200,
  "data": {
    "chargePercent": 45,
    "chargedEnergy": 13.5,
    "chargedTime": "12分钟",
    "chargedAmount": 12.15,
    "totalEstimate": 27.00,
    "status": "0",
    "electricFee": 8.50,
    "serviceFee": 3.65
  }
}
```

**页面使用逻辑（核心数据展示）：**
| 页面显示项 | 对应返回字段 |
|-----------|-------------|
| 电量百分比进度 | `chargePercent` |
| 已充电量 | `chargedEnergy` |
| 已充时长 | `chargedTime` |
| 已充金额 | `chargedAmount` |
| 预估费用 | `totalEstimate` |
| 充电状态判断 | `status`（0=充电中, 1=已完成, 2=已停止）|

- 当 `status === '1'` 或 `'2'` 时，触发 `autoStopFromBackend()` 自动弹出订单弹窗

---

## 4. 停止充电

| 项目 | 内容 |
|------|------|
| **触发时机** | 用户点击「停止充电」按钮 → 确认弹窗 → `doStop()` |
| **调用位置** | [`charging.vue` 第 537 行](file:///d:/NEV_Life/NEV-APP/pages/charge/charging.vue#L537) |
| **API 函数** | `stopCharge(data)` |
| **请求方式** | `POST` |
| **接口地址** | `/app/charge-mini/order/stop` |
| **后端处理** | 更新 `charging_order` 表状态为已停止，计算费用明细 |

**请求参数：**
```json
{
  "orderId": "CO20250101001"
}
```

**返回数据结构：**
```json
{
  "code": 200,
  "data": {
    "orderNo": "CO20250101001",
    "duration": 720,
    "durationText": "12分钟",
    "energy": 13.5,
    "chargedAmount": 12.15,
    "electricFee": 8.50,
    "serviceFee": 3.65,
    "total": 12.15
  }
}
```

**页面使用逻辑：**
- 停止轮询定时器
- 更新 UI 状态为已停止
- 填充订单弹窗数据 `payData`
- 弹出订单支付窗口

---

## 5. 支付订单

| 项目 | 内容 |
|------|------|
| **触发时机** | 用户点击订单弹窗「确认支付」按钮 → `handlePay()` |
| **调用位置** | [`charging.vue` 第 603 行](file:///d:/NEV_Life/NEV-APP/pages/charge/charging.vue#L603) |
| **API 函数** | `payOrder(data)` |
| **请求方式** | `POST` |
| **接口地址** | `/app/charge-mini/order/pay` |
| **后端处理** | 更新 `charging_order` 表支付状态，记录支付信息 |

**请求参数：**
```json
{
  "orderId": "CO20250101001",
  "payMethod": "微信支付"
}
```

**返回数据：** 标准 `AjaxResult`（code 200 表示成功）

**页面使用逻辑：**
- 显示支付中状态
- 支付成功后跳转到订单列表页 `/pages/mine/orders/index`
- 支付失败显示错误提示

## 后端接口汇总

| 序号 | 接口函数 | 方法 | URL | 请求时机 | 操作数据库 |
|:---:|---------|:----:|-----|---------|-----------|
| ① | `getStationDetail` | GET | `/app/charge-mini/station/detail/{id}` | 页面加载 | `charging_station` + `charging_pile` |
| ② | `startCharge` | POST | `/app/charge-mini/order/start` | 初始化充电 | `charging_order` 插入 |
| ③ | `getChargeStatus` | GET | `/app/charge-mini/order/status/{id}` | 每 1 秒轮询 | `charging_order` 查询 |
| ④ | `stopCharge` | POST | `/app/charge-mini/order/stop` | 用户停止充电 | `charging_order` 更新 |
| ⑤ | `payOrder` | POST | `/app/charge-mini/order/pay` | 用户支付 | `charging_order` 更新支付状态 |

## 前端 API 定义文件

所有接口定义位于：[`/api/charge/station.js`](file:///d:/NEV_Life/NEV-APP/api/charge/station.js)

HTTP 请求工具封装位于：`@/utils/request`，默认基础路径为后端服务地址。
