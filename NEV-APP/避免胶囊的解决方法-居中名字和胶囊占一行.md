# 避免胶囊的解决方法：居中名字和胶囊占一行

## 目标

为充电服务模块所有页面添加固定标题栏，文字"充电服务"居中显示，与微信小程序右上角胶囊按钮占同一行，其余内容整体下移。

## 失败的尝试

### 方案一：在每个页面单独写 CSS 类

在每个页面的 template 中添加：

```html
<view class="charge-header" :style="{ paddingTop: statusBarHeight + 'px' }">
  <view class="charge-header-row" style="justify-content: center;">
    <text class="charge-header-title">充电服务</text>
  </view>
</view>
```

在 CSS 中添加：

```scss
.charge-header {
  background: #fff;
  &-row { height: 80rpx; display: flex; align-items: center; padding: 0 24rpx; }
  &-title { font-size: 30rpx; font-weight: 600; color: #333; }
}
```

**结果：** 编译失败，登录时"后端接口连接异常"。

**原因分析：** uni-app 在编译微信小程序时，对多页面中重复出现的 SCSS 嵌套类名（`&-row`、`&-title`）处理存在问题，导致编译产物异常，小程序初始化失败，进而无法调用登录接口。

### 方案二：纯 inline style（无 CSS 类）

完全不使用 CSS 类，所有样式写在内联 style 中：

```html
<view :style="{ paddingTop: statusBarHeight + 'px', background: '#fff' }">
  <view style="height: 80rpx; display: flex; align-items: center; justify-content: center; padding: 0 24rpx;">
    <text style="font-size: 30rpx; font-weight: 600; color: #333;">充电服务</text>
  </view>
</view>
```

**结果：** 同样失败。

**原因分析：** 虽然消除了 CSS 类冲突，但多页面中重复的 inline 模板代码在 uni-app 编译时仍可能产生内部冲突。且每次修改都需要同步 11 个文件，维护成本高，排查困难。

## 成功的方案：独立组件复用

### 核心思路

**将标题栏封装为一个独立的 Vue 组件，定义一次，所有页面引用。**

### 组件文件

`components/charge-header/charge-header.vue`：

```vue
<template>
  <view :style="{ paddingTop: statusBarHeight + 'px', background: bgColor }">
    <view style="height: 80rpx; display: flex; align-items: center; justify-content: center; padding: 0 24rpx;">
      <text :style="{ fontSize: '30rpx', fontWeight: '600', color: textColor }">{{ title }}</text>
    </view>
  </view>
</template>

<script>
const systemInfo = uni.getSystemInfoSync()

export default {
  name: 'ChargeHeader',
  props: {
    title: { type: String, default: '充电服务' },
    bgColor: { type: String, default: '#fff' },
    textColor: { type: String, default: '#333' }
  },
  data() {
    return {
      statusBarHeight: systemInfo.statusBarHeight || 20
    }
  }
}
</script>
```

### 普通页面使用方式（9 个页面）

```vue
<template>
  <view class="xxx-page">
    <charge-header />
    <view class="nav-bar">
      <!-- 原有的导航栏内容，移除 paddingTop 绑定 -->
    </view>
  </view>
</template>

<script>
import ChargeHeader from '@/components/charge-header/charge-header.vue'

export default {
  components: { ChargeHeader },
  // ...
}
</script>
```

### 深色主题页面（charging.vue）

```vue
<charge-header bgColor="rgba(13, 42, 26, 0.95)" textColor="#fff" />
```

### 固定定位页面（index.vue）

index.vue 的搜索栏和地图使用 fixed 定位，需要将标题栏也设为 fixed 并设置 z-index：

```vue
<view style="position: fixed; top: 0; left: 0; right: 0; z-index: 101;">
  <charge-header />
</view>
```

搜索栏 top 调整为标题栏高度以下：

```html
<view class="search-bar" :style="{ top: (statusBarHeight + 40) + 'px' }">
```

地图容器 marginTop 同步增加：

```html
<view class="map-container" :style="{ marginTop: (statusBarHeight + 40 + rpx2px(96)) + 'px' }">
```

## 为什么这个方案能成功

1. **单一职责**：标题栏的 HTML 结构和样式只在一个文件中定义，编译时不会产生多页面重复类名冲突。

2. **每个页面改动极小**：只需 3 行代码（import + 注册 + 标签），大幅降低出错概率。

3. **props 灵活适配**：通过 `bgColor` 和 `textColor` 参数，深色主题页面无需额外 CSS。

4. **纯 inline style**：组件内部完全使用内联样式，不依赖 SCSS 编译，避免嵌套选择器（`&-row`、`&-title`）在跨文件时的编译问题。

5. **`statusBarHeight` 在组件内独立获取**：通过 `uni.getSystemInfoSync()` 在模块顶层获取，无需依赖父页面的 mixin 数据，组件自给自足。

## 关键经验

- 在 uni-app 多页面项目中，**避免在多个页面文件中定义相同的 CSS 类名**，尤其是使用了 SCSS 嵌套语法（`&-`）的类名。
- 优先使用**组件化**方式复用 UI 模块，而非在多个文件中拷贝粘贴代码。
- 排查编译问题时，采用**逐页验证**策略：先确认单页可用，再逐步扩展，快速定位问题页面。
