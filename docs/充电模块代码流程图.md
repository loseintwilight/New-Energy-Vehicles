## 三端划分

| 端 | 说明 | 关键页面 / 接口 |
|---|---|---|
| **用户端 (App)** | 找站 → 扫码充电 → 支付 → 查看记录 | `pages/charge/*`, `pages/mine/charging/*` |
| **商户端 (小程序)** | 工作台、站点/桩管理、费率、订单、结算 | `pages/mine/charge-pile/*` |
| **PC 管理端** | 费率全局配置、商户审核、数据统计 | `ruoyi-ui/views/business/chargingrate/*` |

## 核心业务流程

### 1. 用户端：找站 → 充电 → 支付

```
打开充电页 (pages/charge/index.vue)
    │
    ├─ H5 定位 / 手动选城市
    │
    ├─ 地图展示附近站点标记 (mapMarkers)
    │       │
    │       └─ 点击站点标记
    │               │
    │               ▼
    │       GET /app/charge-mini/station/detail/{stationId}
    │       └─ StationController.detail()
    │               │
    │               ▼
    │       显示站点详情 (pages/charge/detail.vue)
    │       ├─ 站点信息 (名称/地址/电话/营业时间)
    │       ├─ 充电桩列表 + 空闲状态
    │       ├─ 费率信息 (电价 + 服务费)
    │       └─ 用户评价
    │
    ├─ 搜索充电站
    │       │
    │       ▼
    │   GET /app/charge-mini/station/search
    │       └─ StationController.search(keyword, lat, lng, page)
    │
    └─ 选择空闲枪 → 扫码/输入枪号
            │
            ▼
        POST /app/charge/order (创建订单)
            │
            ▼
        充电中 (pages/charge/charging.vue)
            ├─ 实时 soc、电量、时长
            ├─ 当前费用 (根据费率时段动态计算)
            │
            ├─ 手动停止 / 充满自停
            │
            ▼
        PUT /app/charge/order (更新结算数据)
            ├─ total_energy, total_amount
            ├─ end_time, duration, end_soc
            ├─ rate_detail (JSON 记录所用费率)
            └─ order_status = completed
            │
            ▼
        支付 → pay_status = paid
            │
            ▼
        碳积分发放 (carbon_earned)
```

### 2. 商户端：工作台 → 管理

```
工作台 (pages/mine/charge-pile/dashboard.vue)
    │
    ├─ 今日总营收 / 订单数 / 充电量
    │   └─ GET /app/charge/dashboard
    │       └─ AppDashboardController
    │
    ├─ 各站点今日数据
    │   └─ ChargingStationMapper.selectDashboardStations()
    │
    └─ 最近订单
        └─ ChargingStationMapper.selectDashboardRecentOrders()
    │
    ▼
站点管理 (pages/mine/charge-pile/station-list.vue)
    │
    ├─ GET /app/charge/station/listByMerchant/{merchantId}
    │   └─ order by create_time desc
    │
    ├─ 新增站点 (pages/mine/charge-pile/station-add.vue)
    │   └─ POST /app/charge/station
    │       └─ 含营业执照、场地证明上传
    │
    └─ 编辑站点
        └─ PUT /app/charge/station
    │
    ▼
充电桩管理 (pages/mine/charge-pile/pile-list.vue)
    │
    ├─ GET /app/charge/pile/station/{stationId}
    │
    ├─ 新增桩 (pages/mine/charge-pile/pile-add.vue)
    │   └─ POST /app/charge/pile
    │
    └─ 编辑/删除桩
    │
    ▼
费率管理 (pages/mine/charge-pile/rate-list.vue)
    │
    ├─ GET /app/charge/rate/station/{stationId}
    │   └─ order by sort_order asc
    │
    ├─ 编辑费率 (pages/mine/charge-pile/rate-edit.vue)
    │   └─ POST/PUT /app/charge/rate
    │
    └─ 费率时段 (峰/谷/平)
        └─ GET /app/charge/rate/period/list → order by sort_order asc
    │
    ▼
订单管理 (pages/mine/charge-pile/order-list.vue)
    │
    ├─ GET /app/charge/order/list
    │   └─ order by create_time desc
    │
    └─ 订单详情 → settlement-center.vue (结算中心)
    │
    ▼
运营报表 (pages/mine/charge-pile/operation-report.vue)
    └─ 统计分析数据
```

```

```

## 费率计算逻辑

```
用户扫码 → 查费率
    │
    ▼
GET /app/charge/rate/station/{stationId}
    │  返回该站点所有启用费率 (is_active=1, sort_order asc)
    │
    ▼
匹配当前时间 → 查询费率时段
    │  GET /app/charge/rate/period/list
    │  返回峰/谷/平时段 (sort_order asc)
    │
    ▼
计算: 电价 × 充电量 + 服务费 × 充电量 = 总价
    │
    ▼
订单结算时写入 rate_detail (JSON 格式)
    记录: 所用费率ID、时段、单价、电量、费用明细
```

## 关键排序规则

| 接口 / 页面 | 排序字段 | 排序方向 | 说明 |
|---|---|---|---|
| 充电站列表 | `create_time` | desc | 最新的站排前面 |
| 附近/搜索站点 | 距离计算 | 前端计算 | `distance` 由前端实时计算 |
| 充电费率 | `sort_order` | asc | 管理员手动控制顺序 |
| 费率时段 | `sort_order` | asc | 管理员手动控制顺序 |
| 充电订单 | `create_time` | desc | 最新订单排前面 |
| 碳减排统计 | `create_time` | desc | 最新统计排前面 |

## 数据表结构

### stad_charging_station (充电站)

| 字段 | 类型 | 说明 |
|------|------|------|
| station_id | bigint | 主键 |
| station_name | varchar | 站点名称 |
| station_code | varchar | 站编码 |
| merchant_id | bigint | 所属商户 |
| province / city / district / address | varchar | 地址信息 |
| longitude / latitude | decimal | 经纬度坐标 |
| geo_hash | varchar | 地理哈希 |
| total_piles / available_piles / occupying_piles | int | 桩数量统计 |
| open_time / close_time | time | 营业时间 |
| parking_fee | decimal | 停车费 |
| service_phone | varchar | 服务电话 |
| facilities_info | varchar | 设施信息 |
| images | varchar | 站点图片 |
| apply_status | varchar | 申请状态 |
| station_status | varchar | 站点状态 |
| business_license / site_proof | varchar | 资质文件 URL |

### stad_charging_pile (充电桩)

| 字段 | 类型 | 说明 |
|------|------|------|
| pile_id | bigint | 主键 |
| station_id | bigint | 所属站点 |
| pile_code | varchar | 枪号/桩编码 |
| pile_type | varchar | 桩类型 (快充/慢充) |
| pile_status | varchar | 桩状态 (空闲/占用/故障) |
| power | decimal | 功率 (kW) |

### stad_charging_rate (充电费率)

| 字段 | 类型 | 说明 |
|------|------|------|
| rate_id | bigint | 主键 |
| station_id | bigint | 所属站点 |
| rate_name | varchar | 费率名称 |
| pile_type | varchar | 适用桩类型 |
| is_active | char(1) | 是否启用 |
| effective_from / effective_to | datetime | 有效期 |
| sort_order | int | 排序号 |

### stad_charging_rate_period (费率时段)

| 字段 | 类型 | 说明 |
|------|------|------|
| period_id | bigint | 主键 |
| rate_id | bigint | 所属费率 |
| period_name | varchar | 时段名称 (峰/谷/平) |
| start_time / end_time | time | 时段起止 |
| energy_price | decimal | 电价 |
| service_price | decimal | 服务费 |
| sort_order | int | 排序号 |

### stad_charging_order (充电订单)

| 字段 | 类型 | 说明 |
|------|------|------|
| order_id | bigint | 主键 |
| order_no | varchar | 订单号 |
| user_id | bigint | 用户ID |
| station_id / station_name | bigint/varchar | 站点 |
| pile_id / pile_code | bigint/varchar | 充电桩 |
| rate_id / rate_period_id | bigint | 费率/时段 |
| start_time / end_time | datetime | 起止时间 |
| duration | int | 充电时长 (分钟) |
| start_soc / end_soc | decimal | 起止电量 (%) |
| total_energy | decimal | 充电量 (kWh) |
| energy_price / service_price | decimal | 电价 / 服务费单价 |
| discount_amount | decimal | 优惠金额 |
| total_amount | decimal | 总金额 |
| rate_detail | varchar | 费率明细 (JSON) |
| order_status | varchar | 订单状态 |
| pay_status | varchar | 支付状态 |
| payment_method | varchar | 支付方式 |
| transaction_id | varchar | 交易流水号 |
| carbon_earned | decimal | 获得碳积分 |
