# 充电页城市选择与重新定位代码流程图

## 概述

充电主页 (`pages/charge/index.vue`) 的城市选择功能实现了两个核心流程：
1. **城市选择**：从 `city-select` 页面选定城市后，地图自动重新定位到城市坐标
2. **重新定位**：点击"重新定位"按钮后，城市名立即刷新（不再卡住）

关键设计：通过 `cityJustChanged` 标记区分"主动选择城市"和"GPS 定位"，避免 `onShow` 中的重复触发逻辑冲突。

---

## 流程一：选择城市 → 地图重新定位

```
充电主页 (pages/charge/index.vue)
    │
    ├─ onLoad()
    │   ├─ await initLocation() → uni.getLocation({ type: 'gcj02' }) → 获取 GPS 坐标
    │   │   └─ setLocation(lat, lng) → 更新 mapCenter + queryParams.lat/lng
    │   └─ fetchStationList() → 以 GPS 坐标查询附近充电站
    │
    ├─ onReady()
    │   └─ retryMoveToLocation() → 6次重试，每次500ms，确保地图视角就位
    │
    ▼
用户点击城市选择器 (city-selector)
    └─ goCitySelect()
        └─ uni.navigateTo({ url: '/pages/charge/city-select' })
    │
    ▼
城市选择页 (pages/charge/city-select.vue)
    │
    ├─ loadCityList()
    │   ├─ 构建 CITY_LETTER_MAP (16个山东省城市 → 首字母)
    │   └─ 构建 CITY_DISTRICTS (每个城市的区县列表)
    │
    ├─ 用户点击城市 "青岛市"
    │   └─ selectCity('青岛市')
    │       │
    │       ├─ ① 标准化城市名
    │       │   └─ name = '青岛市'.replace(/[市区县].*$/, '') + '市' → '青岛市'
    │       │
    │       ├─ ② 写入 storage
    │       │   ├─ uni.setStorageSync('selectedCity', '青岛市')
    │       │   ├─ uni.setStorageSync('selectedCityCoords', { lat: 36.0671, lng: 120.3826 })
    │       │   │   └─ 坐标来源: CITY_COORDS 字典 (16个山东省城市预定义坐标)
    │       │   └─ uni.setStorageSync('cityJustChanged', true)  ← 关键标记
    │       │
    │       └─ ③ uni.navigateBack() → 返回充电主页
    │
    ▼
充电主页 onShow() 被触发
    │
    ├─ 检测 cityJustChanged 标记
    │   ├─ uni.getStorageSync('cityJustChanged') → true ✓
    │   ├─ uni.removeStorageSync('cityJustChanged') → 清除标记 (避免重复触发)
    │   ├─ this.currentCity = '青岛市' → 更新UI显示
    │   ├─ this.queryParams.pageNum = 1 → 重置分页
    │   ├─ this.stationList = [] → 清空旧列表
    │   └─ this.onCityChanged('青岛市')  ← 进入城市变更处理
    │
    ▼
onCityChanged(cityName = '青岛市')
    │
    ├─ uni.showLoading({ title: '定位中...' })
    │
    ├─ ① 读取存储的城市坐标
    │   └─ uni.getStorageSync('selectedCityCoords') → { lat: 36.0671, lng: 120.3826 }
    │       │
    │       ├─ 找到了 ✓ → 走本地坐标路径 (不依赖网络API)
    │       │
    │       └─ 没找到 → 降级: amap.geocode('青岛市')
    │           └─ GET https://restapi.amap.com/v3/geocode/geo?address=青岛市
    │
    ├─ ② setLocation(lat, lng)
    │   ├─ this.queryParams.lat = 36.0671
    │   ├─ this.queryParams.lng = 120.3826
    │   └─ this.mapCenter = { lat: 36.0671, lng: 120.3826 }
    │       └─ 触发 <map :latitude="mapCenter.lat" :longitude="mapCenter.lng"> 响应式更新
    │
    ├─ ③ uni.hideLoading()
    │
    ├─ ④ await fetchStationList(true)
    │   └─ GET /app/charge-mini/station/list?lat=36.0671&lng=120.3826&pageNum=1&pageSize=10
    │       └─ 后端以青岛市坐标查询附近充电站并返回
    │
    └─ ⑤ moveToCoords(36.0671, 120.3826)
        ├─ this.mapCenter = { lat: 36.0671, lng: 120.3826 } → 同步绑定数据
        └─ tryMove() 重试机制 (最多10次, 每次200ms)
            ├─ if (this.mapCtx) → mapCtx.moveToLocation({ lat, lng })
            └─ if (!this.mapCtx) → uni.createMapContext('chargeMap') → 重试
```

## 流程二：点击重新定位 → 城市名立即更新

```
用户点击地图右下角 "重新定位" 按钮
    │
    ▼
reLocate()
    │
    ├─ 防重复: if (this.locating) return
    │
    ├─ uni.showLoading({ title: '定位中...' })
    │
    ├─ ① 获取 GPS 坐标
    │   └─ this.getUniLocation()
    │       └─ uni.getLocation({ type: 'gcj02', timeout: 10000 })
    │           └─ 读取微信小程序 Sensor 面板模拟坐标 或 手机真实GPS
    │
    │   失败降级链:
    │   ├─ getHighAccuracyLocation() → isHighAccuracy: true
    │   └─ getNetworkFallbackLocation() → 普通精度
    │
    ├─ ② setLocation(pos.latitude, pos.longitude)
    │   └─ 更新 queryParams.lat/lng + mapCenter
    │
    ├─ ③ mapCtx.moveToLocation({ lat, lng })
    │   └─ 地图视图立即移动到 GPS 坐标
    │
    ├─ ④ fetchStationList(true)
    │   └─ 以 GPS 坐标重新查询充电站
    │
    ├─ ⑤ refreshCurrentCity(lat, lng)  ← 解决"卡住不动"的关键
    │   │
    │   ├─ 立即同步: this.currentCity = '济南市'
    │   │   └─ uni.setStorageSync('selectedCity', '济南市')
    │   │   └─ UI 立即显示 "济南市" ，不再卡在之前选择的城市名
    │   │
    │   └─ 异步优化: amap.reverseGeocode(lng, lat)
    │       └─ GET https://restapi.amap.com/v3/geocode/regeo?location=lng,lat
    │           │
    │           ├─ 成功 → 解析真实城市名 (如 "青岛市")
    │           │   ├─ this.currentCity = '青岛市'
    │           │   └─ uni.setStorageSync('selectedCity', '青岛市')
    │           │   └─ UI 更新为真实城市名
    │           │
    │           └─ 失败 → 保持 '济南市' (不影响功能)
    │
    └─ ⑥ uni.hideLoading() + this.locating = false
```

## Storage 键值说明

| Key | 类型 | 写入方 | 读取方 | 作用 |
|-----|------|--------|--------|------|
| `selectedCity` | String | city-select / reLocate | index | 当前选中的城市名称 |
| `selectedCityCoords` | {lat, lng} | city-select | index.onCityChanged | 选中城市的经纬度坐标 |
| `cityJustChanged` | Boolean | city-select | index.onShow | 标记城市已被用户主动选择，触发重新定位 |

## onShow 的两种触发路径

```
onShow() 被触发
    │
    ├─ cityJustChanged === true ?
    │   │
    │   ├─ YES → 用户刚选择了城市
    │   │   ├─ 清除 cityJustChanged 标记
    │   │   ├─ 更新 currentCity = savedCity
    │   │   └─ onCityChanged(savedCity) → 坐标定位 + 数据刷新
    │   │
    │   └─ NO → 其他页面返回 / 首次加载
    │       │
    │       ├─ savedCity !== currentCity ?
    │       │   ├─ YES → 兜底: onCityChanged(savedCity)
    │       │   └─ NO → 无需处理
    │       │
    │       └─ (首次加载时: onLoad 已处理 GPS 定位,
    │           onShow 检测到城市一致, 不做额外操作)
```
