# 卖车端代码流程图

## 核心业务流：商户端看板 → 管理

```
车辆管理首页 (pages/mine/vehicle/vehicle-dashboard.vue)
    │
    ├─ 车辆总数 / 今日订单 / 今日营收 / 活跃用户
    │   └─ GET /merchant/vehicle/dashboard
    │       └─ VehicleController.dashboard()
    │           └─ VehicleService.getDashboardStats()
    │
    ├─ 最近订单展示 (Top 3)
    │   └─ GET /business/vehicle/order/list?pageNum=1&pageSize=3
    │
    ├─ 最新评论展示 (Top 3)
    │   └─ GET /business/review/list?pageNum=1&pageSize=3
    │
    ├─ 快捷入口 (4大功能卡片 2×2)
    │   ├─ 车辆列表 → vehicle-list
    │   ├─ 订单中心 → vehicle-order-list
    │   ├─ 库存管理 → stock-manage
    │   └─ 价格管理 → price-manage
    │
    └─ 更多管理弹窗
        ├─ 新增车辆 → vehicle-add
        ├─ 价格管理 → price-manage
        ├─ 客户评价 → review-list
        ├─ 二手车管理 → used-car-list
        └─ 系统设置 → system-settings
    │
    ▼
车辆列表 (pages/mine/vehicle/vehicle-list.vue)
    │
    ├─ GET /merchant/vehicle/list
    │   └─ VehicleController.list()
    │       └─ VehicleService.selectVehicleList()
    │
    ├─ 搜索 (车型名称 keyword) / 类型筛选 (新车/二手车/全部)
    │
    ├─ 状态筛选 (在售/下架/售罄) + 价格排序
    │
    ├─ 新增车辆 (pages/mine/vehicle/vehicle-add.vue)
    │   └─ POST /merchant/vehicle
    │       └─ VehicleController.add()
    │           └─ VehicleService.insertVehicle()
    │               └─ 含车辆规格 VehicleSpec 同步写入
    │
    ├─ 编辑车辆 (复用 vehicle-add.vue)
    │   └─ PUT /merchant/vehicle
    │       └─ VehicleController.edit()
    │
    └─ 删除车辆
        └─ DELETE /merchant/vehicle/{vehicleIds}
    │
    ▼
车辆详情 (pages/mine/vehicle/vehicle-detail.vue)
    │
    ├─ GET /merchant/vehicle/detail/{vehicleId}
    │   └─ VehicleController.detail()
    │       └─ VehicleService.selectVehicleDetailById()
    │
    ├─ 展示: 大图(images[0]) / 品牌 / 年款 / 续航 / 电池 / 价格
    │
    ├─ 编辑车辆 → vehicle-add.vue
    │
    ├─ 电池诊断
    │   └─ GET /merchant/vehicle/{vehicleId}/battery
    │       └─ VehicleController.batteryDiagnosis()
    │           └─ VehicleService.selectVehicleBatteryDiagnosis()
    │
    └─ 销售数据
        └─ GET /merchant/vehicle/{vehicleId}/sales
            └─ VehicleController.getVehicleSales()
    │
    ▼
订单管理 (pages/mine/vehicle/vehicle-order-list.vue)
    │
    ├─ 顶部统计条 (今日订单 / 今日营收 / 待交付)
    │   └─ GET /business/vehicle/order/list
    │       └─ 前端计算: todayRevenue = SUM(total_amount) WHERE status ≠ '3'(已取消)
    │
    ├─ 订单列表 (按状态筛选 + 时间范围筛选)
    │   ├─ 全部 / 待付款(0) / 待交付(1) / 已完成(2) / 已取消(3)
    │   └─ 今天 / 近7天 / 本月 / 全部
    │
    ├─ 订单详情 (pages/mine/vehicle/vehicle-order-detail.vue)
    │   └─ GET /business/vehicle/order/{orderId}
    │       └─ 含: 金额大卡 / 车辆信息(名称/品牌/年款/续航) / 客户信息(姓名/电话)
    │           / 订单信息(编号/状态/时间) / 支付信息(方式/金额/时间)
    │
    └─ PC端订单管理
        └─ GET/POST /business/unified/order
            └─ StadUnifiedOrderController
    │
    ▼
库存管理 (pages/mine/vehicle/stock-manage.vue)
    │
    ├─ GET /merchant/vehicle/list
    │   └─ VehicleController.list()
    │
    ├─ 概览卡片 (总车型数 / 总库存量 / 低库存预警)
    │
    ├─ 搜索 (车型名称) / Tab切换 (全部/在售/下架)
    │
    └─ 库存详情 (pages/mine/vehicle/stock-detail.vue)
        └─ 编辑库存数量 + 状态
    │
    ▼
价格管理 (pages/mine/vehicle/price-manage.vue)
    │
    ├─ GET /business/price/list
    │
    ├─ 全选 / 批量调价
    │   └─ PUT /business/price
    │
    └─ 更新单车价格
    │
    ▼
金融方案 (pages/mine/vehicle/finance-list.vue)
    │
    ├─ 方案总数 / 在用数 / 综合利率 概览卡片
    │
    ├─ 搜索 / 状态筛选 (全部/在用/停用)
    │
    ├─ 新增方案 (pages/mine/vehicle/finance-edit.vue)
    │   └─ POST /business/vehicle/finance
    │
    └─ 编辑方案
        └─ PUT /business/vehicle/finance
    │
    ▼
二手车管理 (pages/mine/vehicle/used-car-list.vue)
    │
    ├─ GET /car/used/list
    │
    ├─ 搜索 / 状态筛选 (在售/已售/待检测)
    │
    ├─ 新增二手车 (pages/mine/vehicle/used-car-add.vue)
    │   └─ POST /car/used
    │
    └─ 二手车详情 (pages/mine/vehicle/used-car-detail.vue)
        └─ GET /car/used/detail?id={usedId}
            └─ 电池检测 / 估值 / 认证信息
    │
    ▼
客户评价 (pages/mine/vehicle/review-list.vue)
    │
    ├─ GET /business/review/list
    │
    ├─ 综合评分 / 总评价数 / 好评率 概览条
    │
    └─ 评价详情 (pages/mine/vehicle/review-detail.vue)
        └─ GET /business/review/{reviewId}
    │
    ▼
售后管理 (pages/mine/vehicle/after-sale.vue)
    │
    ├─ 工单总数 / 处理中 / 已完成 概览条
    │
    └─ 状态筛选 (全部/处理中/已完成)
```

## 订单状态流转

```
待付款(0) ──▶ 待交付(1) ──▶ 已完成(2) ──▶ 用户评价
    │
    ▼
已取消(3)
```
