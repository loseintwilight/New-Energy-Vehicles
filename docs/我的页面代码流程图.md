## 我的首页 (index.vue) 数据加载流程

```
onLoad / onShow
    │
    ├─ syncUserInfo()    同步用户信息
    │   └─ 从 Vuex store 读取 name/phone/avatar
    │
    └─ loadAllData()     并行加载所有数据
        │
        ├─ loadWalletInfo()
        │   └─ GET /app/wallet/info → 钱包余额
        │
        ├─ loadCarbonPoints()
        │   └─ GET /app/carbon/overview → 碳积分 + CO₂减排量
        │
        ├─ loadCollectionCount()
        │   └─ GET /app/collection/count → 收藏数量
        │
        ├─ loadCouponCount()
        │   └─ GET /app/coupon/count → 优惠券数量
        │
        └─ loadOrderStatusCount()
            └─ GET /app/order/status/count → 各状态订单数
```

## 子页面流程详解

### 1. 个人信息与头像 (info/ + avatar/)

```
info/index.vue (个人信息展示)
    │
    ├─ onLoad → loadUserInfo()
    │   └─ GET /app/user/profile → 用户详细信息
    │       └─ 展示: 头像、昵称、用户名、手机号、邮箱、角色
    │
    ├─ 点击头像 → avatar/index.vue (修改头像)
    │   ├─ 显示当前头像
    │   ├─ 选择图片 (uni.chooseImage)
    │   ├─ handleUpload → 上传头像
    │   │   ├─ POST /common/upload/minio (MinIO)
    │   │   └─ PUT /app/user/avatar → 更新头像URL
    │   └─ Vuex store 同步更新头像
    │
    └─ 点击"编辑资料" → info/edit.vue
        ├─ onLoad → 传入用户数据
        ├─ 编辑昵称/邮箱/性别等
        └─ handleSubmit → PUT /app/user/profile → 更新资料
```

### 3. 我的订单 (orders/)

```
orders/index.vue (我的订单)
    │
    ├─ 标签栏: 全部 / 待确认 / 已确认 / 服务中 / 已完成 / 已取消
    │   └─ 状态映射: pending_confirm → confirmed → in_service → completed → cancelled
    │
    ├─ onLoad → loadOrders(status?)
    │   └─ GET /app/order/list?status=&page=&size=
    │       └─ 返回: 订单列表 (分页)
    │           └─ 不同 bizType 显示不同样式标签
    │
    ├─ 下拉刷新 → onRefresh → reload orders
    ├─ 上拉加载 → loadMore → next page
    │
    └─ 点击订单 → orders/detail.vue
        └─ GET /app/order/detail/{id} → 订单详情
```

### 4. 充电记录 (charging/)

```
charging/index.vue (充电记录)
    │
    ├─ 列表展示: 站点名、充电量、费用、时长、时间
    ├─ onLoad → GET /app/charging/order/list
    │
    └─ 点击记录 → charging/detail.vue
        └─ 详细: 桩号、起止SOC、费率明细、碳积分
```

### 5. 碳积分 (carbon/)

```
carbon/index.vue (碳积分)
    │
    ├─ [积分总览]
    │   ├─ 当前积分、累计减排 (kg CO₂)
    │   ├─ 累计获得 / 累计消耗 / 累计兑换
    │   └─ GET /app/carbon/overview
    │
    ├─ [获取方式]
    │   ├─ 充电减排 → 充电行为获得积分
    │   ├─ 绿色出行 → 步行/骑行等
    │   ├─ 每日签到
    │   └─ 环保任务
    │
    ├─ [积分流水]
    │   ├─ 筛选: 全部 / 获得 / 消耗
    │   └─ GET /app/carbon/ledger/list?type=&page=
    │       └─ 按 ledger_id desc (最新在前)
    │
    └─ [积分商城] 
        └─ 兑换商品 → 消耗积分
```

### 6. 我的收藏 (favorites/)

```
favorites/index.vue (我的收藏)
    │
    ├─ 标签筛选: 全部 / 充电站 / 服务商 / 资讯
    ├─ onLoad → GET /app/collection/list?type=
    │   └─ 分页加载
    │
    └─ 取消收藏 → DELETE /app/collection/{id}
```

### 7. 优惠券 (coupons/)

```
coupons/index.vue (优惠券)
    │
    ├─ 标签: 未使用 / 已使用 / 已过期
    ├─ onLoad → GET /app/coupon/list?status=
    └─ 点击使用 → 跳转对应业务页面
```

### 8. 钱包 (wallet/)

```
wallet/index.vue (钱包)
    │
    ├─ 余额展示
    ├─ 交易流水列表
    ├─ GET /app/wallet/info → balance
    └─ GET /app/wallet/transactions → 流水 (分页)
```

### 9. 端切换 (switch/) — 申请成为商户

```
switch/index.vue (端切换 - 申请商户)
    │
    ├─ 选择身份类型:
    │   ├─ 维保服务端 (shop_owner)
    │   ├─ 充电桩端   (charger)
    │   └─ 商家端     (merchant)
    │
    ├─ 填写表单信息 (不同身份表单不同)
    │   ├─ 通用: 姓名、手机号、省份城市、法人代表
    │   ├─ 维保端: 门店名称、门店地址、门店图片
    │   ├─ 充电桩端: 充电站名称、站点编码
    │   └─ 商家端: 商家名称、营业执照
    │
    ├─ 营业执照/资质上传
    │   ├─ POST /common/upload/minio (MinIO 直链)
    │   └─ 回退: POST /common/upload (本地存储)
    │
    └─ handleSubmit → POST /app/end-switch/apply
        └─ 参数: identity, [form 各字段], businessLicense
            └─ 后端写入 stad_merchant 表 → 待审核
```

### 10. 消息通知 (messages/)

```
messages/index.vue (消息通知)
    │
    ├─ 列表: 系统消息 / 订单通知 / 活动通知
    ├─ onLoad → GET /app/message/list
    │   └─ 分页, 按 create_time desc
    │
    └─ 点击消息 → 标记已读 → PUT /app/message/read/{id}
```

### 11. 预约记录 (reservation/)

```
reservation/index.vue (预约记录)
    │
    ├─ 标签: 全部 / 待服务 / 已完成 / 已取消
    ├─ onLoad → GET /app/reservation/list
    │
    └─ 点击 → 预约详情 / 取消预约
```

## 端切换完整流程

```
pages/mine/switch/index.vue (我的 → 端切换)
    │
    ├─ 选择身份 (水平按钮切换)
    │   ├─ 维保服务端 → formMaintenance
    │   ├─ 充电桩端   → formCharging
    │   └─ 商家端     → formBusiness
    │
    ├─ 选择省份 → 城市 (联动选择器)
    │   └─ cities 根据 currentProvince 动态计算
    │
    ├─ 填写表单
    │   ├─ 法人代表 (legal_person)
    │   ├─ 联系电话
    │   └─ 其他业务字段
    │
    ├─ 上传营业执照图片
    │   ├─ uni.chooseImage → 选择图片
    │   ├─ POST /common/upload/minio → MinIO URL (优先)
    │   │   └─ 如果 MinIO 不可用 → 回退本地
    │   └─ 回显图片预览
    │
    └─ handleSubmit → POST /app/end-switch/apply
        ├─ identity: 维保/充电/商家
        ├─ legal_person, phone, province, city
        ├─ businessLicense (营业执照URL)
        └─ 各身份特有字段
            │
            ▼
        AppEndSwitchController.apply()
            │
            ├─ 校验必填字段
            ├─ 生成 merchant_code
            ├─ 设置 apply_status = 'pending'
            │
            └─ INSERT INTO stad_merchant(...)
                │
                ▼
```
