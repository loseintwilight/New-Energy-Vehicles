# 维保模块代码流程图

## 核心业务流：商户端看板 → 管理

```
商户首页 (pages/mine/service/index.vue)
    │
    ├─ 门店总数 / 今日订单 / 累计评价 / 综合评分
    │   └─ GET /maintenance/dashboard/stats
    │       └─ MaintainDashboardController
    │           └─ MaintenanceOrderMapper.selectDashboardStats()
    │
    ├─ 最近评价展示
    │   └─ GET /maintenance/dashboard/recentReviews
    │       └─ MaintenanceOrderMapper.selectRecentReviews()
    │
    └─ 快捷入口 (门店管理 / 创建门店 / 订单管理 / 数据统计)
    │
    ▼
门店管理 (pages/mine/service/shopList/index.vue)
    │
    ├─ GET /maintenance/shop/list
    │   └─ MaintainShopController
    │       └─ IStadMaintenanceShopService.selectStadMaintenanceShopList()
    │
    ├─ 搜索门店 (keyword) / 状态筛选 (待审核/营业中/已停用)
    │
    ├─ 创建门店 (pages/mine/service/shopEdit/index.vue)
    │   └─ POST /maintenance/shop/create
    │       └─ 状态默认 0=待审核
    │
    ├─ 编辑门店
    │   └─ PUT /maintenance/shop/update
    │
    └─ 删除门店
        └─ DELETE /maintenance/shop/delete
    │
    ▼
订单管理 (pages/mine/service/orderList/index.vue)
    │
    ├─ 顶部统计条 (全部/待确认/已确认/已完成/已取消)
    │   └─ GET /maintenance/order/stats
    │       └─ MaintainOrderController
    │           └─ MaintenanceOrderMapper.selectOrderStats()
    │
    ├─ 订单列表 (按状态筛选)
    │   └─ GET /maintenance/order/list?orderStatus=0|1|2|3|4
    │       └─ IStadMaintenanceOrderService.selectStadMaintenanceOrderList()
    │
    ├─ 订单详情 (pages/mine/service/orderList/detail.vue)
    │   └─ GET /maintenance/order/detail?order_id={id}
    │       └─ 含门店信息、车辆信息、预约信息、费用明细
    │
    ├─ 取消订单
    │   └─ POST /maintenance/order/cancel
    │       └─ orderStatus → 4, cancelReason → 取消原因
    │
    └─ 修改订单状态/支付
        └─ POST /maintenance/order/update
    │
    ▼
评价管理 (pages/mine/service/shopComment/index.vue)
    │
    └─ GET /maintenance/order/reviews
        └─ MaintenanceOrderMapper.selectStadMaintenanceOrderReviewList()
            └─ 仅查询 rating IS NOT NULL 的记录
    │
    ▼
数据统计 (pages/mine/service/dataSettings/index.vue)
    │
    ├─ 概览卡片 (门店总数/订单总数/总收入/平均评分)
    │   └─ GET /maintenance/dashboard/stats
    │       └─ revenue = SUM(total_amount) WHERE pay_status='1'
    │
    ├─ 订单状态分布
    │   └─ GET /maintenance/dashboard/statusDist
    │       └─ 按 order_status 分组统计 (待确认→橙/已确认→蓝/服务中→紫/已完成→绿/已取消→灰)
    │
    ├─ 月度订单趋势
    │   └─ GET /maintenance/dashboard/monthlyTrend?year={year}
    │       └─ 按 YEAR(create_time) 过滤, 按月分组统计
    │
    └─ 门店评分排行
        └─ GET /maintenance/dashboard/shopRanking
            └─ MaintenanceShopMapper.selectShopRanking()
```

## 订单状态流转

```
待确认(0) ──▶ 已确认(1) ──▶ 服务中(2) ──▶ 已完成(3) ──▶ 用户评价(评分+内容)
    │
    ▼
已取消(4)
```
