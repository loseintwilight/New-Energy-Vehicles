```java
public AjaxResult getStationList(Double lat, Double lng, 
        Integer pageNum, Integer pageSize,
        String orderByColumn, String isAsc, String filter) {
    // 1. 根据经纬度分页查询附近电站，SQL内置距离排序
    int offset = (pageNum - 1) * pageSize;
    List<StationVO> list = stationMapper.selectStationListWithDistance(
            lat, lng, offset, pageSize, orderByColumn, isAsc, filter);

    // 2. 丰富返回数据（空闲桩数、标签、实时价格等）
    for (StationVO item : list) {
        enrichStationItem(item);
    }

    Long total = stationMapper.selectStationCount(filter);
    return AjaxResult.success({rows: list, total: total});
}
```

#### 2. 后端 — 获取站详情 (StationServiceImpl.getStationDetail)

```java
public AjaxResult getStationDetail(Long stationId) {
    // 1. 查询充电站基本信息
    StadChargingStation station = stationMapper.selectStationById(stationId);
    StationDetailVO detail = new StationDetailVO();
    detail.setName(station.getStationName());
    detail.setAddress(station.getAddress());
    detail.setLat(station.getLatitude());
    detail.setLng(station.getLongitude());
    detail.setTotalPiles(station.getTotalPiles());

    // 2. 获取费率时段列表（峰谷平电价）
    List<RateVO> rates = stationMapper.selectRatesByStationId(stationId);
    detail.setTimePrices(rates);

    // 3. 获取充电桩列表及实时状态（空闲/占用/故障）
    List<PileVO> piles = pileMapper.selectPileListByStationId(stationId);
    detail.setPiles(piles);

    // 4. 实时统计空闲桩数
    int freeCount = 0;
    for (PileVO p : piles) {
        if ("0".equals(p.getPileStatus())) freeCount++;
    }
    detail.setFreePiles(freeCount);

    return AjaxResult.success(detail);
}
```

### 阶段二：开始充电 & 充电流程

#### 4. 后端 — 开始充电 (OrderServiceImpl.startCharge)

```java
public AjaxResult startCharge(Long userId, Long stationId, 
                              String pileNo, Double energy, Integer soc) {
    // 1. 查询充电桩 & 校验是否空闲
    PileVO pile = pileMapper.selectPileByPileNo(stationId, pileNo);
    if (!"0".equals(pile.getPileStatus())) 
        return AjaxResult.error("充电桩不可用");

    // 2. 匹配费率：根据桩类型(dc/ac) + 当前时段
    String pileType = pile.getPileType();
    List<RateVO> rates = stationMapper.selectRatesByStationId(stationId);
    for (RateVO rate : rates) {
        if (当前时间 in rate.getStartTime() ~ rate.getEndTime()) {
            electricPrice = rate.getElectricPrice();  // 电费单价
            servicePrice = rate.getServicePrice();     // 服务费单价
            break;
        }
    }
    // 兜底：0.35元电费 + 0.55元服务费 = 0.90元/度

    // 3. 生成订单 & 更新桩状态为充电中
    String orderNo = "CO" + System.currentTimeMillis();
    orderMapper.insertOrder(orderNo, userId, stationId, pileNo, ...);
    pileMapper.updatePileStatus(pile.getPileId(), "1");  // 1=充电中
    stationMapper.syncStationPileCounts(stationId);       // 同步站点空闲数

    return AjaxResult.success({orderNo, electricPrice, servicePrice, totalPrice});
}
```

#### 5. 后端 — 轮询状态 & 自动完成 (OrderServiceImpl.getChargeStatus)

```java
public AjaxResult getChargeStatus(String orderNo) {
    OrderVO order = orderMapper.selectOrderByOrderNo(orderNo);
    
    // 测试模式：5秒自动充满
    int durationSecs = (now - order.getStartTime()) / 1000;
    int chargePercent = Math.min(99, durationSecs * 100 / 5);

    if (durationSecs >= 5) {  // 自动完成
        double electricFee = targetEnergy * electricUnitPrice;
        double serviceFee = targetEnergy * serviceUnitPrice;
        double totalAmount = electricFee + serviceFee;

        // 更新订单 & 释放充电桩
        orderMapper.updateOrderForStop(orderNo, durationSecs, totalAmount);
        pileMapper.updatePileStatus(pileId, "0");        // 0=空闲
        stationMapper.syncStationPileCounts(stationId);   // 同步站桩数
    }

    return AjaxResult.success({
        chargePercent, chargedEnergy, chargedAmount, status, ...
    });
}
```

```javascript
async initCharge() {
    const res = await startCharge({
        stationId: this.stationId,
        pileNo: this.pileNumber,
        energy: this.targetEnergy
    });
    this.orderNo = res.data.orderNo;
    this.isCharging = true;

// ② 1秒轮询充电状态
startPolling() {
    this.timer = setInterval(() => {
        this.fetchChargeStatus();
    }, 1000);

async fetchChargeStatus() {
    const res = await getChargeStatus(this.orderNo);
    this.chargePercent = res.data.chargePercent;  // 环形进度条
    this.chargedEnergy = res.data.chargedEnergy;   // 已充电量
    this.chargedAmount = res.data.chargedAmount;   // 已充金额
    this.realTimePower = 实时功率值;                 // 功率折线图
    this.addPowerPoint(parseFloat(this.realTimePower));

    if (res.data.status === '1') {  // 后端自动完成
        this.autoStopFromBackend(res.data);
    }
},

// ④ 支付处理

    await payOrder({ orderId: this.orderNo, payMethod: '微信支付' });
    uni.showToast({ title: '支付成功，碳积分已发放' });
},
```

### 核心数据流总结

```
┌─────────── 充电地图 & 站列表 ───────────┐
用户打开小程序 → initLocation(定位) 
  → fetchStationList(lat, lng) 
  → 后端SQL按距离排序查询 → 返回rows
  → 渲染地图标记 markers + 列表 cards
  → 点击卡片 → navigateTo(详情页)
                    │
            ┌───────▼─────────── 开始充电 ──────────┐
            站详情 → 选择桩 → 跳转充电页 
            → startCharge(stationId, pileNo, energy)
            → 后端匹配费率 → 写入订单DB → 更新桩状态(充电中)
            → 返回 orderNo
                    │
            ┌───────▼──────── 充电中（1秒轮询） ──────┐
            getChargeStatus(orderNo) 每1秒调用
            → 后端计算进度 → 返回实时数据
            → 前端渲染：环形进度 / 电量 / 金额 / 功率曲线
            → 满5秒(测试模式) → 后端自动完成
            → 释放充电桩 → 更新订单为已完成
                    │
            ┌───────▼─────────── 支付 & 碳积分 ──────┐
            弹出支付窗 → payOrder → 碳积分发放
            → 充电记录存入"我的订单" → 流程结束
```

### 关键设计要点

| 要点 | 实现方式 |
|------|----------|
| **费率时段匹配** | 后端根据桩类型(dc/ac) + 当前时间匹配峰谷平时段，支持跨天（如22:00-07:00） |
| **桩状态联动** | 开始→置为充电中(1)，完成→释放为空闲(0)，同步更新电站表可用/占用桩数 |
| **测试模式** | 5秒模拟充满，前端1秒轮询，方便调试演示 |
| **定位降级** | uni.getLocation → 高德SDK → 手动输入地址，三级降级保证可用 |
| **距离排序** | SQL 内置经纬度距离计算（Haversine 公式），支持综合/距离/价格/评分排序 |
